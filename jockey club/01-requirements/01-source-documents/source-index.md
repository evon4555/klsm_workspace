# Source Document Index

## Purpose

This folder stores original source documents for the Jockey Club project.

## Structure

- `01-it-pmo\` stores project-wide source documents.
- `02-templates\` stores project templates.

## Update Rule

- Keep original source documents unchanged.
- Add Jockey Club project-wide documents here when they apply to multiple
  workstreams or requirements.
- Add requirement-specific documents under the relevant requirement package.
- Use `D:\Workspace\standard product` for baseline product behavior when the
  project source does not restate it.
