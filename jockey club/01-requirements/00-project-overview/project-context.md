# Project Context

## Project Identity

`jockey club` is a customer project workspace derived from the SaaS baseline in
`D:\Workspace\standard product`.

## Business Shape

The project should be evaluated as a customer-specific implementation on top of
the standard product. Requirement packages in this workspace define the latest
Jockey Club-specific deltas.

## Scope Rules

- Jockey Club-specific behavior belongs here.
- Shared baseline behavior belongs in `D:\Workspace\standard product`.
- If a Jockey Club requirement reveals reusable product behavior, promote it to
  the standard product only after the user confirms it is product-wide.

## Context Usage Rules

Use context in this order:

1. Requirement package
2. Jockey Club project context
3. Standard product baseline
4. Shared company context
5. Shared QA system
