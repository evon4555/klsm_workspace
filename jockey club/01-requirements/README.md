# Jockey Club Requirements

This folder stores Jockey Club requirements, source documents, project rules,
module work, and QA design artifacts.

## Structure

```text
01-requirements\
  00-project-overview\  project context, glossary, rules, AI entries
  01-source-documents\  original project-wide sources and templates
  02-subprojects\      customer workstreams and modules
```

## Usage

Use this folder for Jockey Club-specific behavior. Baseline product behavior
should be read from `D:\Workspace\standard product`.
