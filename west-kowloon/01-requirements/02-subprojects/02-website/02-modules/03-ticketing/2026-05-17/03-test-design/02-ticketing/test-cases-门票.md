## [SECTION] Scope Summary

- Feature: Admission Ticket (general admission) full E2E — Date Selection → Ticket Selection (with Real-Name Verification) → Order Confirmation → Payment (Cybersource) → Order Detail → Merchandise Add-On + Refund + Reschedule (placeholder).
- Source authority: **Mindmap > PRD**. Authoritative: `..\..\01-input\02-mindmap\009-014-购票中的门票展开页*.png` + `..\..\01-input\02-mindmap\002-项目详情-购票展开页.png` (Refund / Reschedule sub-trees).
- Risk level: **High** (revenue-critical; payment integration; refund workflow; Real-Name compliance).
- Assumptions: SIT environment; sample event with Admission Ticket Ticket Types + Real-Name-required Ticket Types; Cybersource sandbox available; refund enabled on test event (per Open Question — TBD).
- Open issues: see `..\..\02-analysis\requirement-risk-review-购票.md` § Open Questions (authoritative).
- **Note on Transfer**: mindmap 013 (Admission Ticket Order Detail) does NOT list Transfer, while mindmap 007 (Seat Selection Ticket Order Detail) does. TC-041 covers this as a yellow placeholder pending product intent verification, paired with TC-078 as the alternative-direction placeholder.
