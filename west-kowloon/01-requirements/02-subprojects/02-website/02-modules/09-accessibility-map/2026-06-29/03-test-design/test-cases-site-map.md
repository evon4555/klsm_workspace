# Test Cases - Site Map

## [SECTION] Scope Summary

- Feature: Site Map / 网站地图 (F1-F8, signed-off 2026-06-30)
- Source authority: PRD section 4.1 is the working source because this package has no mindmap; Figma node `20062:8236` is UI reference.
- Signed decisions:
  - Q-1 = a: Activities are grouped by activity tags only.
  - Q-2 = b: Customer Service uses Figma's 4 entries.
  - Q-3 = a: verify filtered results after navigation; do not hard-assert URL parameter names.
  - Q-4 = a: effective categories and venues mean backend enabled/active.
  - Q-5 = a: footer content uses ad positions `foot_1` to `foot_3`.
  - Q-6 = a: user-facing label is Site Map / 网站地图.
  - Q-7 = a: unauthenticated personal-center style links redirect to login and return to the target page after login.
- Confirmed assumptions: U-1..U-6 all confirmed.
- Risk level: Medium. The page is mostly navigational, but incorrect links or stale dynamic data can block discovery and account-service entry.
- Deferred scope: full WCAG 2.1 audit, operational ad-position testing beyond footer 1-3, and backend configuration CRUD are out of this package.
- Test data baseline:
  - Active event categories: Music, Dance, Theatre.
  - Inactive event category: Archived Category.
  - Active activity tags: Family Activities, Workshops, Guided Tours.
  - Inactive activity tag: Retired Tag.
  - Membership BU/category examples: MKPM / HKPM Patrons, M+ / M+ Member, M+ / M+ Young Member.
  - Active venues: HKPM, M+, WestK.
  - Inactive venue: Closed Venue.
  - Footer positions: `foot_1` = The Authority, `foot_2` = The District, `foot_3` = News & Support.
