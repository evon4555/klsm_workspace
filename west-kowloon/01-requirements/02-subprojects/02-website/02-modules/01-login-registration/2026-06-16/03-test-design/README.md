# 03-test-design

This folder keeps the active test-design deliverables for the 2026-06-16
login/registration package.

Root-level files are the files that should be used by current indexes,
automation, dashboard flows, or follow-up requirement work.

## Active Deliverables

- `test-cases-registration-login.md`
- `test-cases-registration-login.xlsx`
- `test-cases-cookies.xlsx`
- `test-cases-registration-login_2026-06-12.fixed-2026-06-16.xlsx`
- `test-cases-registration-login_2026-06-12.scope-clean-2026-06-16.xlsx`
- `test-cases-registration-login_2026-06-12.scope-clean-2026-06-16.env-fixed-2026-06-18.xlsx`
- `review-closeout-2026-06-15.md`

The two `scope-clean-2026-06-16` workbooks are retained in the root because they
represent the 2026-06-16 requirement-change test-case version. The
`env-fixed-2026-06-18` workbook is also retained because downstream story-case
generation currently reads it as source material.

## Archive

`_archive` contains historical generation scripts, intermediate workbook
backups, diff reports, and iteration notes. These files are kept for traceability
but are not the current working artifacts.
