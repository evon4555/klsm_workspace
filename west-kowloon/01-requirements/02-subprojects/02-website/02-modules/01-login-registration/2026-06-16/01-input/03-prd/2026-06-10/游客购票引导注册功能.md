# 游客购票引导注册功能

## 需求背景

当前系统支持游客模式购票。

游客模式能够有效降低购票门槛，提高支付转化率，但无法将游客沉淀为会员资产，导致：

- 用户复购率较低

- 会员增长速度有限

- 无法持续进行营销触达

- 私域用户资产沉淀不足

为提升会员转化率，在不影响游客购票体验的前提下，增加购票后会员激活机制。

西九需求：[西九网站登录和订单联系方式的调整](https://wtvrhpmlkj.feishu.cn/wiki/WZWOwDNpKiIRU8keu2zcwBL4njf)

## 需求目标

业务目标：提升游客转会员比例。

用户目标：用户完成购票后，立即注册成为注册用户并可获得专属福利。

产品目标：不增加购票流程复杂度，不影响订单支付转化率。

## 适用范围

### 适用渠道

- PC官网

- H5官网

- 海外票务站点

- 港澳台票务站点

### 适用对象

游客购票用户。

## 业务规则

核心流程描述：游客购票 → 身份验证 → 提交订单 → 升级游客临时账号为注册用户 → 完成支付 → 自动发放福利

```mermaid
graph TD

    A[订单确认页：<br>选择并填写联系邮箱/手机]

    A --> B[填写OTP验证码]
    B --> |验证正确| C[继续购票流程]

    C -->|邮箱/手机已注册| D[不显示会议转化勾选项]
    C -->|邮箱/手机未注册| E[显示会员转化勾选项]
    E --> G[提交订单]
    D --> G


    G --> K[是否勾选会员转化勾选项]


    K -->|否| L[完成支付流程]
    L --> P([结束])
    K -->|是| M[游客账号升级为注册账号]
    M --> N[完成支付流程]
    N --> O[提示注册成功]
    O --> P

    B --> |验证错误| R[不可继续购票]
    R --> B```

### 邮箱/手机校验

用户填写联系人邮箱/手机后：

系统自动校验：

- 邮箱/手机格式是否合法

- 邮箱/手机是否已注册会员账号

    - 已注册邮箱/手机：不展示会员转化入口。用户正常完成购票。

    - 未注册邮箱/手机：显示会员转化选项“同意同步注册为西九文化区注册用户”（勾选项，非必填，默认不勾选）

### 提交订单（唤起支付前）

1. 若用户已勾选会员转化——系统自动将当前游客临时账号升级为注册用户账号：

    1. 按用户选择，记录邮箱或手机号作为账号的绑定信息，另一项留空；

    2. 同时将登录态从“游客”变更为“注册用户”

    3. 需要在账号上标记“游客购票转化”的信息——如何实现？

    4. 当前订单本身关联当前账号，账号升级后关联关系不变

    5. 发放游客购票转化会员专属礼包（如有）

2. 若用户未勾选会员转化——系统不升级游客账号，正常完成订单支付流程。

后续按注册用户的相关逻辑执行。

### 订单确认页

#### 调整联系邮箱/手机选择和录入方式

1. 增加一个联系邮箱/手机的选项，由用户自己选择填写哪个信息

    1. 选中的为必填项。例如：选择邮箱，则邮箱未必填项，手机非必填，反之亦然；

    2. 如果邮箱和手机都有填写，只提交选择的那项。即前端提交时，只返回选择的内容，订单也只记录选择的内容。例如，用户2项均填写，但是选择了邮箱，那么提交订单时只返回邮箱

2. **联系人姓名调整为非必填**，且填写输入库的位置移到邮箱/手机后

3. 增加OTP验证码功能，验证通过才可以提交订单——**仅针对游客**模式有这个，登录用户不需要

4. 下方显示的发送信息，显示用户选择的那项，如果没有填写则提示未填写

#### 账号校验

鼠标离开邮箱/手机的输入框后，进行账号唯一性校验。如果发现没有对应的用户账号，则显示引导注册选项。
