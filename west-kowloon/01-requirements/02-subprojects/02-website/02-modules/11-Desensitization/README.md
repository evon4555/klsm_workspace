# Desensitization Module

本模块承接西九项目跨渠道、跨业务模块的个人敏感信息（PII）脱敏要求。

当前覆盖方向包括：

- Website 前台个人中心、会员卡、订单详情、票夹及入场码；
- PDA 扫码后的用户信息展示；
- 后台会员 360、门票/座票订单、会员卡及报表；
- BI 定制报表与 Dashboard 的 PII 暴露检查；
- 集中存储、阿里云 KMS、权限控制及审计。

日期包直接放在本目录下，例如 `2026-07-30`。每个日期包必须先完成
`02-analysis` 需求整合并由测试经理确认，之后才可在 `03-test-design`
生成正式测试用例。
