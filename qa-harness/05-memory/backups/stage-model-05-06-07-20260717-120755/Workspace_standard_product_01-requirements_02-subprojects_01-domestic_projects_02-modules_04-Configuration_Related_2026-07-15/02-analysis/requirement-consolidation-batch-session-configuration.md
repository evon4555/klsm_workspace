## 3. 测试范围

### 3.1 范围内（后台配置，共 6 条能力）

| 编号 | 能力 | 说明 |
|----|----|----|
| F1 | 场次列表批量操作入口 | 管理员在场次管理列表选择一个或多个场次后，打开「场次批量操作」菜单 |
| F2 | 批量修改场次可售票组 | 管理员选择「批量修改场次可售票组」，为已选场次批量设置可售票组 |
| F3 | 批量修改是否在日历上展示 | 管理员选择「批量修改是否日历展示」，批量设置已选场次是否展示在日历上 |
| F4 | 批量修改是否在场次列表中显示 | 管理员选择对应批量操作，批量设置已选场次的显示类型，如常驻显示、到期显示、不显示 |
| F5 | 预生成变更预览 | 管理员在提交前点击「预生成」，系统展示原值 / 修改后值的对比预览，并允许删除本次不提交的行 |
| F6 | 确认修改与回显 | 管理员点击「确认修改」后，系统保存剩余行的配置，并在列表或详情中回显最新结果 |
