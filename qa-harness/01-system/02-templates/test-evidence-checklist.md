---

## [SECTION] Requirement Evidence

- [ ] Requirement link or identifier is recorded.
- [ ] Business goal is recorded.
- [ ] Acceptance criteria are recorded.
- [ ] Open questions are recorded.
- [ ] Requirement risk notes are available for medium-risk or high-risk work.

---

## [SECTION] Test Design Evidence

- [ ] Test strategy or test notes are available.
- [ ] Test cases or checklist are available.
- [ ] Requirement-to-case mapping exists for important features.
- [ ] Test case review result exists for medium-risk or high-risk work.
- [ ] Test data and environment needs are recorded.

---

## [SECTION] Execution Evidence

- [ ] Tester is recorded.
- [ ] Execution date is recorded.
- [ ] Environment is recorded.
- [ ] Version, build, branch, or deployment identifier is recorded.
- [ ] Case result is recorded.
- [ ] Screenshots are attached for key UI flows.
- [ ] Logs are attached for errors or backend behavior.
- [ ] API request and response are attached where relevant.
- [ ] Database checks are attached where relevant.
- [ ] Defect links are attached for failed cases.
- [ ] Blocked and skipped reasons are documented.

---

## [SECTION] Defect Evidence

- [ ] Defect summary is clear.
- [ ] Preconditions are recorded.
- [ ] Reproduction steps are recorded.
- [ ] Actual result is recorded.
- [ ] Expected result is recorded.
- [ ] Evidence is attached.
- [ ] Severity and priority are assigned.
- [ ] Fix verification evidence is recorded.

---

## [SECTION] Regression Evidence

- [ ] Regression scope is recorded.
- [ ] Regression cases or checklist are available.
- [ ] Regression execution result is recorded.
- [ ] Automation report is linked if available.
- [ ] Manual evidence is attached for critical flows.
- [ ] Remaining regression risk is recorded.

---

## [SECTION] Execution Review Evidence

- [ ] Test report is available.
- [ ] Defect summary is available.
- [ ] Remaining risk list is available.
- [ ] Not-tested scope is documented.
- [ ] Automated and manual execution results are reconciled.
- [ ] QA readiness outcome is stated.
- [ ] Execution review sign-off is recorded.
