# Domain Glossary

This glossary is the baseline product glossary. Add only reusable product
terminology here.

| Term | Working Meaning | Notes |
|---|---|---|
| standard product | Baseline SaaS product used to create customer projects. | Use as the source for shared product behavior. |
| admin backend | Back-office management capability in the baseline product. | Customer projects may extend or configure it. |
| customer project | Project workspace derived from the standard product. | West Kowloon and Jockey Club are customer projects. |
| project-specific extension | Behavior added or changed for one customer project. | Keep it in the customer workspace unless confirmed product-wide. |
