# Translation Glossary

Authority for baseline product terminology. Keep this glossary focused on
product-wide terms.

| Source | Target | Notes |
|---|---|---|
| 标品 | standard product | Baseline SaaS product. |
| 标品后台 | standard-product backend | Hyphenate when used as an adjective. |
| 后台 | admin backend | Use when referring to the management system. |
| 项目 | customer project | Use when the context is a SaaS customer implementation. |

## Maintenance

When a term is customer-specific, add it to that customer's project glossary
instead. Promote it here only after confirming that the term applies to the
baseline product.
