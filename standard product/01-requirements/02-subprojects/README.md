# Subprojects

Use this folder for baseline product areas or workstreams.

Create deeper folders only when there is real source material or active QA work.
For customer-specific modules, use the relevant customer project workspace
instead.

## Index

| Subproject | Path | Status | Notes |
|---|---|---|---|
| Domestic projects | `01-domestic projects` | Active | Contains baseline domestic ticketing modules. |
| Overseas projects | `02-overseas projects` | Placeholder | Reserved for overseas baseline work; no active package indexed yet. |

## Routing

- Put reusable standard-product behavior under the matching subproject here.
- Put customer-specific deltas under `D:\Workspace\west-kowloon` or
  `D:\Workspace\jockey club`.
- For new dated requirement packages, use `<module>\<yyyy-mm-dd>` with
  `01-input` through `07-release-feedback` and a package-level `package.md`.
