# Standard Product Requirements

This folder stores baseline product requirements, source documents, product
rules, module work, and QA design artifacts.

## Structure

```text
01-requirements\
  00-project-overview\  baseline product context, glossary, rules, AI entries
  01-source-documents\  original product-wide sources and templates
  02-subprojects\      product areas or workstreams
```

## Subproject Index

| Subproject | Path | Notes |
|---|---|---|
| Domestic projects | `02-subprojects\01-domestic projects` | Active baseline ticketing workstream. |
| Overseas projects | `02-subprojects\02-overseas projects` | Placeholder until source material is added. |

## Usage

Use this folder for reusable product behavior. Customer-specific deltas belong
under the customer project workspace, not here.
